Diagnosis (not fixed, per spike scope; *superseded by the onnxruntime 1.24 rerun below: the ORT-pin option does not work, the cause is the hub 2.x symlinked blob layout*): `.venv-cpu` has onnxruntime 1.31.0 and huggingface_hub 2.2.0. hub 2.x stores blobs in a shared, sharded `hub/blobs/<2 chars>/<sha>` layout and the snapshot files are symlinks into it, so `vieneu_prefill.onnx` and its external data file `vieneu_backbone_shared.data` resolve into different directories. onnxruntime 1.31 rejects external data that resolves outside the model's directory. `.venv-gpu` (huggingface_hub 0.36.2, per-repo blob folder) uses the torch path and is unaffected. Plausible fixes for M2 or a re-run: pin `huggingface_hub<1.0` in the CPU environment, pin an older onnxruntime, or download the ONNX folder with `local_dir` (real files, no symlinks).

## S1: Emotion transfer from reference clips

Script: `spikes/m0/s1_matrix.py` (vieneu 3.8.3, v3 Turbo, `.venv-gpu`, backend auto, `infer()` defaults). Run from `spikes/m0`:
`.venv-gpu/Scripts/python.exe s1_matrix.py --narrator "Đức Trí" --male "Thái Sơn" --female "Mỹ Duyên"`. It exited 0, printed 18 `done` lines and 20 rows, and VieNeu printed no warnings.

**Setup:**
- Presets: narrator "Đức Trí", male "Thái Sơn", female "Mỹ Duyên". All three are Southern and were chosen by the owner after the S3 listening note. The female was switched from "Kim Thanh" because debugging found that preset carries about 5x more 4-12 kHz vowel noise than the others.
- Reference clips: `out/s1/refs/{role}_{emotion}.wav` (18 clips, 48 kHz). They were made with VoxCPM2 controllable cloning from the three presets above, on a Colab T4.
- Three refs are under 3 s: narrator_angry 2.24 s, female_fearful 2.56 s and male_angry 2.72 s. They were not altered. The narrator_angry clone came out at only 1.92 s for a 9-word line, versus 3.36 s for the preset version.
- Each cell is a single unseeded sample, because VieNeu `infer()` has no seed parameter. A rerun would produce different audio.
- The listening page `out/s1/listen.html` puts three audios side by side for each emotion row: the VoxCPM2 ref, the VieNeu preset and the VieNeu clone from the ref. There are also 2 tag rows with the preset plus a non-verbal tag. Ratings: 0 = no difference, 1 = slight, 2 = clear emotion in the clone column.

|---|---|---|---|

**Counts:**
- **E2 = 4**: happy, sad, angry and whisper each got rating 2 for at least one role. Fearful got 0 for every role.
- **B = 2**: male_happy and male_tag were marked broken.
- **Tags:** `[cười]` (male_tag) was broken, and `[thở dài]` (female_tag) was rated 0, so it was not audible. Neither tag reached rating 1 or higher, so non-verbal tags are not usable.
- **Note:** female_neutral was rated 2. The clone differs audibly from the preset even for neutral, which means the VoxCPM2 ref itself shifts style/timbre, not only emotion. Part of the female "emotion" ratings may come from this timbre shift.

**S1 verdict: PASS** under the brief's rules (E2 = 4 ≥ 3 and B = 2 ≤ 2).

Controller ruling: enable emotion refs only for (voice, emotion) pairs rated 2 — narrator/angry, male/angry, male/whisper, female/happy, female/sad; all other pairs (including every fearful) use the neutral ref + prosody; drop non-verbal tags.
